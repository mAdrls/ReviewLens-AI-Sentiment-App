End-to-End NLP Pipeline Architecture

Step 1
Text Preprocessing

Lowercasing, regex tokenization, URL removal, English stopword filtration.

Step 2
TF-IDF Vectorization

Unigram and bigram extraction, sublinear term frequency scaling, feature sparse matrix.

Step 3
Logistic Classifier

Multinomial logistic regression with L2 regularization and L-BFGS optimization.

Step 4
Explainability & Output

Softmax class probabilities, keyword attribution scoring, and human-readable explanation.

Academic Model Limitations & Observations

  • Compact Training Set: Trained on a 100-sample academic demonstration dataset of consumer electronics reviews.
  • Sarcasm and Context: Sarcastic expressions (e.g. "Great, another broken piece of plastic!") can challenge n-gram models because they contain positive words with negative intent.
  • Vocabulary Boundary: Slang or product-specific abbreviations not present in the TF-IDF vocabulary default towards neutral background priors.
  • No Heavy Infrastructure: Designed to run in milliseconds on any lightweight student laptop without GPUs, cloud endpoints, or external dependencies.

About ReviewLens AI & Project Guide

Project documentation, technology stack, and college demonstration cheat sheet

Project Purpose & Architecture

ReviewLens AI is an end-to-end sentiment analytics web application created for academic demonstration. It enables e-commerce product managers and consumers to extract actionable insights from customer feedback without requiring complex database systems or costly external APIs.

Unlike static mockups, ReviewLens AI features a genuine Python machine learning classification pipeline built with Scikit-learn, exposed via a clean Flask REST API, and visualized using modern UI components and Chart.js.

Technology Stack

Frontend: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Chart.js, Lucide Icons.
Backend: Python 3.11, Flask, Flask-CORS REST API.
Machine Learning: Scikit-learn (TF-IDF + Logistic Regression), Joblib serialization.
Persistence: Zero-database local JSON architecture and in-memory session history.

Teacher Demonstration Walkthrough

Follow these 5 steps when demonstrating this project to your professor or evaluator:

  1. Overview Dashboard: Highlight the computed KPI metrics and show how the charts reflect the actual aggregation of sample reviews.
  2. Product Catalog: Open the Product Explorer, click on SoundWave Pro Headphones, and demonstrate the sentiment filter buttons (Positive, Neutral, Negative).
  3. Review Analyzer: Click on one of the preloaded example chips, then type a brand new original sentence (e.g. "The battery lasted two hours and the mic sounds muffled") to prove the ML model evaluates live.
  4. Explainable AI: Show the probability distribution bars and keyword contribution chips that explain why the model made its prediction.
  5. Model Performance Page: Walk through the Precision/Recall table, the confusion matrix, and explain the TF-IDF + Logistic Regression pipeline.
